What it is for

  • ComponentsA React, Vue, Svelte, or Solid view checks the fields it renders with transformSchema.
  • FormsRequire the fields collected so far and leave the rest optional.
  • API clientsAn OpenAPI schema becomes the Zod schema, and a Zod schema can be written back out.
  • StreamsCheck a JSON tool call from AG-UI, SSE, a ReadableStream, or a Node stream while it arrives.
